Cada letra do alfabeto manual de Libras é reconhecida a partir de 21 pontos-chave da mão extraídos pelo MediaPipe, classificados por um modelo de Regressão Logística treinado com 4.411 imagens reais (97,8% de F1 macro no teste). Letras confirmadas se juntam em palavras e frases, que são traduzidas pro inglês e faladas em voz alta — tudo rodando localmente, sem nenhuma API de IA generativa paga. Detalhes técnicos completos no README do projeto.

Projeto de portfólio — MediaPipe + scikit-learn/PyTorch + Flask. Alfabeto treinado com o Brazilian Sign Language Alphabet Dataset (Passos, Fernandes & Comunello, UNIVALI).
